# COSMOS — THE LIVING UNIVERSE
Static Three.js/WebGL observatory.

Upload these three files together:
- index.html
- style.css
- script.js

The Solar System is one complete interactive scene: Sun, eight planets, Moon, artificial satellite concept, asteroid belt, comet and stars. Click objects to inspect them; use TRAVEL / FOCUS for smooth camera movement.

Galaxies, nebulae and black holes use procedural/educational 3D representations where literal 3D surfaces are unavailable. Distances and sizes are compressed for exploration.

GitHub Pages: Settings → Pages → Deploy from branch → main → root.

Important: all three files must remain separate. Do not paste JavaScript into index.html.
